📊 Analisador de Vendas

Sobre o projeto

Este projeto foi desenvolvido como parte da minha jornada de aprendizado em **Python**, com o objetivo de praticar conceitos fundamentais de programação por meio de uma situação prática: a análise de vendas de uma empresa.

A proposta é desenvolver um programa capaz de receber valores de vendas e apresentar informações importantes sobre o faturamento.

🎯 Objetivo

Criar um programa que permita registrar valores de vendas e realizar cálculos para gerar um resumo dos resultados.

🛠️ Tecnologias utilizadas

- Python 3

📚 Conceitos praticados

- Entrada de dados com `input()`
- Conversão de tipos com `int()` e `float()`
- Estruturas de repetição (`for` e `range`)
- Listas para armazenamento de informações
- Operações matemáticas
- Funções para análise de valores

🚀 Funcionalidades

- Registro de valores de vendas.
- Cálculo do faturamento total.
- Cálculo da média das vendas.
- Identificação da maior venda.
- Identificação da menor venda.
- Exibição de um relatório final.

▶️ Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Execute o arquivo `Analisador_de_vendas.py`.
4. Siga as instruções exibidas no terminal.

Durante o desenvolvimento, busquei compreender a lógica por trás de cada estrutura utilizada, fortalecendo minha capacidade de resolver problemas por meio da programação.
